# CampusConnect

CampusConnect is the event-registration platform for TechNova 2026, the college technical fest.
Last updated: 2026-09-12

## Stack
- Frontend: React + Vite
- Backend: FastAPI
- Database: PostgreSQL 16
- Hosting platform: Railway
